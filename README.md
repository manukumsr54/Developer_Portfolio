## Architecture

The project follows a modular frontend architecture designed to keep the application maintainable and data-driven.

```text
Developer_Portfolio/
│
├── frontend/
│   ├── src/
│   │   ├── components/
│   │   ├── sections/
│   │   ├── data/
│   │   ├── hooks/
│   │   ├── lib/
│   │   ├── assets/
│   │   ├── App.jsx
│   │   ├── index.css
│   │   └── main.jsx
│   │
│   └── package.json
│
└── backend/
    ├── routes/
    ├── middleware/
    ├── controllers/
    ├── database/
    ├── server.js
    └── package.json
```

The frontend is kept data-driven wherever practical, allowing projects, technologies, hackathons, and journey information to be updated without unnecessary changes to component logic.

## Local Development

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd Developer_Portfolio
```

### 2. Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

The Vite development server will normally be available at:

```text
http://localhost:5173
```

### 3. Start the Backend

Open another terminal:

```bash
cd backend
npm install
npm run dev
```

The backend runs separately from the frontend.

> Configure the required environment variables in the backend `.env` file before enabling database-backed functionality.

---

## Environment Variables

Never commit secrets or credentials to Git.

Example:

```env
PORT=3001
DATABASE_URL=your_database_connection_string
```

Use the project's actual environment variable names when configuring the application.
